# TrueValue App Bug Report - Manual Testing

This repository contains manual testing evidence for the TrueValue mobile application. It includes bug screenshots, video recordings, and a spreadsheet report documenting issues found during testing.

## Overview

The goal of this repository is to capture and present bugs identified in the TrueValue app through manual testing. It serves as a structured defect archive rather than an application source code repository.

## Repository Contents

- `Bugs Screenshot/` - folder containing screenshots and video recordings used as bug evidence
- `True Value App Bug Report_.xlsx` - spreadsheet containing the manual testing bug report

## Purpose

This repository is useful for:

- documenting bugs discovered during manual testing
- attaching visual proof for reported issues
- sharing test evidence in a structured format
- keeping a record of observed defects in the TrueValue mobile app

## Files Included

### Bugs Screenshot

This folder contains image and video files that capture issues found in the app, including UI problems, broken links, filtering issues, alignment issues, and other functional defects.

### Bug Report Spreadsheet

The Excel file contains the main bug report summary and may include:

- bug title
- bug description
- steps to reproduce
- expected result
- actual result
- severity or priority
- supporting evidence

## How to Use This Repository

1. Open `True Value App Bug Report_.xlsx` to review the bug report details.
2. Browse the `Bugs Screenshot/` folder to view supporting screenshots and video clips.
3. Use the evidence when discussing issues with developers, QA teams, or stakeholders.

## Notes

- This repository is intended for manual testing documentation.
- It does not contain application source code.
- The bug report focuses on the TrueValue mobile application.
